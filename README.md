# Stock Trading Platform

A modern full-stack stock trading platform inspired by real-world trading applications, designed to provide users with a seamless and interactive trading experience. The platform offers intuitive portfolio management, market monitoring, secure authentication, and responsive user interfaces suitable for both desktop and mobile devices.

---

## 🚀 Features

- 📈 Interactive trading dashboard
- 💹 Real-time market-style UI
- 🔐 User authentication system
- 📊 Portfolio and holdings management
- 💰 Buy and sell stock simulation
- 📱 Fully responsive design
- ⚡ Fast and optimized frontend experience
- 🗂 Clean project structure and scalable architecture

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/ayush200545/Stock-Trading-Platform.git
```

### 2️⃣ Navigate to Project Directory

```bash
cd Stock-Trading-Platform
```

### 3️⃣ Install Dependencies

#### Frontend

```bash
cd frontend
npm install
```

#### Backend

```bash
cd backend
npm install
```

---

## ▶️ Run the Project

### Start Backend Server

```bash
cd backend
npm start
```

### Start Frontend

```bash
cd frontend
npm start
```
